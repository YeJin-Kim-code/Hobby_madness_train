# 광기의 취미열차
취미 활동을 기록하고 스탬프로 달성 경험을 시각화하며, AI 기반 활동 요약 기능을 제공하는 서비스

# 광기의 취미열차 MVP

## 인증
- 회원가입
- 로그인

## 취미
- 취미 목록 조회

## 기록
- 기록 작성
- 기록 조회
- 기록 수정/삭제

## 스탬프
- 취미별 스탬프 수 조회

## 커뮤니티
- 게시글 작성/조회
- 댓글 작성

## AI
- 활동 요약 기능
- 게시글 요약 기능
- 댓글이 너무 길 경우 요약 기능

## 추후 추가 기능
- 세부 취미 사항 추가(등산, 독서 etc)
- 취미별 업적 모음
- 취미별 기능 추가
- GPS
- 지도 API
- 위치 기반 추천
- 실시간 기능
